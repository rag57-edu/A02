# Part 2: Glossary

- **Branch**: A separate line of development within a Git repository that allows users to work on features or fixes without affecting the main project.

- **Clone**: A copy of a remote repository that is downloaded to a local computer.

- **Commit**: A saved snapshot of changes made to files in a repository.

- **Fetch**: A Git command that retrieves updates from a remote repository without merging them into the local repository.

- **GIT**: A distributed version control system used to track changes in files and collaborate on software development projects.

- **Github**: A cloud-based platform that hosts Git repositories and provides tools for version control and collaboration.

- **Merge**: The process of combining changes from one branch into another branch.

- **Merge Conflict**: A situation that occurs when Git cannot automatically combine changes from different branches and requires user intervention to resolve the differences.

- **Push**: The process of uploading local commits from a computer to a remote repository on GitHub.

- **Pull**: The process of downloading changes from a remote repository and merging them into a local repository.

- **Remote**: A version of a repository that is hosted on another computer or service, such as GitHub.

- **Repository**: A storage location that contains project files, folders, and the complete history of changes managed by Git.
